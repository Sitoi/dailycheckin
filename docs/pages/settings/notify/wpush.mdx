# WPUSH

### 配置示例

```json filename="config.json" copy
{
  "WPUSH_APIKEY": "",
  "WPUSH_CHANNEL": "",
  "WPUSH_TOPIC_CODE": "",
  "MERGE_PUSH": ""
}
```

|           参数            |                                                                                       说明                                                                                       |
| :-----------------------: | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
|   _**WPUSH_APIKEY**_    | 用户 API Key，在 [WPUSH 设置页](https://wpush.cn/settings) 获取，[官方文档](https://wpush.cn/docs)                                                                                |
|  _**WPUSH_CHANNEL**_    | 推送渠道，默认 `wechat`；支持 wechat / app / sms / mail / webhook / dingtalk / feishu / wechat_work / clawbot / qqbot 等                                                         |
| _**WPUSH_TOPIC_CODE**_  |                                                      可选，Topic 广播编码；不填仅发送给自己                                                      |
|   _**MERGE_PUSH**_      |                                                    **true**: 将推送消息合并；**false**: 分开推送                                                     |
